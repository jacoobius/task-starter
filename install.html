Install the Focus Lock extension

A website isn't allowed to control other browser tabs. The Focus Lock is a small browser extension that does it for Task Starter: while your timer is counting, it pauses every new page except Task Starter and the links you saved for your task.

It is optional. Task Starter works fully without it. It works in Google Chrome and Microsoft Edge on a computer, not on phones.

What you need

  • Google Chrome or Microsoft Edge on a Windows, Mac or ChromeOS computer.
  • A browser profile you control. School or work browsers often block this kind of install. If step 5 is greyed out, that is why.
  • The download below (6 small files in one zip, about 8 KB).

Download the Focus Lock (zip)

Install it (about 2 minutes)

  1. Download the zip above.
  2. Unzip it. On Windows, right-click the file and choose "Extract All". On a Mac, double-click it. You get a folder called task-starter-focus-lock.
  3. Move that folder somewhere it can stay, such as your Documents folder. The browser runs the extension from this folder, so don't delete it afterwards.
  4. Open the extensions page. Type chrome://extensions into the address bar (in Edge: edge://extensions) and press Enter. Websites can't link to this page, so it has to be typed.
  5. Turn on "Developer mode". It's a switch in the top-right corner in Chrome, or on the left in Edge.
  6. Click "Load unpacked" and choose the task-starter-focus-lock folder: the one that has manifest.json directly inside it.
  7. Reload Task Starter. Open Settings: under "Pause other websites during the timer" it should say the extension is installed.

Check it works

  1. Start a step and press Start timer.
  2. Under the countdown, look for: "Other websites are paused until the timer ends". That line only appears once the extension has confirmed the lock.
  3. Open a new tab, type a site you didn't save as a link, and press Enter. You should see "Paused while you focus".

Good to know

  • The warning. The browser says the extension can "Read your browsing history". It needs to see the address of each page you open to decide whether to pause it. It never saves or sends those addresses anywhere.
  • You're never stuck. The paused page always has "Unlock all sites now". The lock also ends by itself when the timer ends or is paused, when you close the Task Starter tab, when you restart the browser, and after 3 hours at most.
  • Open tabs are left alone. Tabs that were already open before the timer started keep working, so nothing you were doing is lost.
  • Turn it off any time in Task Starter's Settings ("Pause other websites during the timer"), without uninstalling.
  • Updating. Download the zip again, replace the files in your folder, then press the circular reload arrow on the extension's card on the extensions page.
  • Removing. Click "Remove" on the extension's card. You can then delete the folder.

The files in the zip

FileWhat it does
manifest.jsonThe extension's name, version, permissions and list of files
bridge.jsRuns inside the Task Starter page and passes "lock" and "unlock" messages to the extension
background.jsDecides which pages to pause, and ends the lock
blocked.html, blocked.js, blocked.cssThe "Paused while you focus" page
